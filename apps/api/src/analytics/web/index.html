Use a short label such as portfolio, bio, or winter-update. Letters, numbers, and hyphens only. Default portfolio links stay short; custom campaigns include tracking tags.

How these links work

The short portfolio links redirect to your website with a platform tag. Paste the whole link into your profile, bio, post, or message. Custom campaign links include their tags directly. This is especially useful for WhatsApp and other apps that may not send referral information.

If someone forwards a tagged link elsewhere, it keeps the original platform label. The label records the link’s source; it doesn’t reveal a visitor’s identity or prove which app they used.
